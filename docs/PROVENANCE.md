# Provenance

Updated 28 October 2026.

Codex and Claude assisted planning, research, analysis code, figures,
documentation and manuscript revision. Manuscript assistance went beyond
language editing. Numerical plots are generated by scripts from archived
simulation outputs, laboratory measurements or derived results; those sources
are distinguished in the experiment guides. Human authors remain responsible
for the submitted work and its interpretation.

The root implementation is a NumPy reconstruction. The separate
[`reproducibility/`](../reproducibility) workflow retains the original
scikit-learn algorithms and a newly dated 792-fit reproduction, including 72
newly fitted estimators. These are not recovered historical model weights.
Experiment B also contains three older laboratory-model artifacts.

Checks establish computational agreement within their recorded scope. They do
not validate the assumed equivalent-cell mapping, actual Z50 pack temperatures
or thermal-runaway warning performance. See the technical
[model boundaries](../reproducibility/docs/MODEL_AND_LIMITS.md) and dated audit
records for those distinctions.

Git commits preserve the recorded authorship and upload chronology. Co-author
trailers appear where recorded; their presence or absence is not a complete
record of assistance, experimental execution dates or personal review.
