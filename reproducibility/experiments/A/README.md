# Experiment A: complete forecasting implementation

[`train.py`](train.py) implements feature construction, three forecasting baselines, ridge and histogram gradient boosting estimators, nested group validation, hyperparameter selection, model fitting, metric aggregation and figure generation.

The target is a generated A123-equivalent laboratory-cell surface-temperature surrogate. It is not measured battery-pack temperature or thermal-runaway ground truth.

## Run the experiment

From the `reproducibility` directory, install the pinned dependencies and run:

```text
python -m pip install -r experiments/A/requirements.txt
python experiments/A/train.py --output experiments/A/my_new_run --save-models
python -m unittest discover -s experiments/A/tests -p test_models.py -v
python experiments/A/verify_saved_models.py --run-dir experiments/A/reproduction_run_2026-10-28
```

The default scientific source root is `data/workspace`; the archived input directory is `data/workspace/APCOM_Draft_Experiments_2026-10-27/experiment_a`. These defaults are resolved relative to the code's repository location, independent of the terminal's working directory. To use another source tree:

```text
python experiments/A/train.py --source-root /path/to/scientific_source_root --input-dir /path/to/archived_experiment_a --output /path/to/new_output --save-models
```

The output directory must not exist and must be outside both read-only input trees. The program checks scientific input, protocol and archived implementation hashes before starting. It uses normal installed Python packages; no machine-specific package paths are embedded in the implementation. `--save-models` writes all 72 newly fitted outer estimators, each named `NEW_REFIT_...joblib`. Omit the flag to retain predictions and selection records without estimator serialization.

## Actual inputs, features and models

| Item | Implementation and meaning |
|---|---|
| Source measurements | `APCOM_Study_2026-10-22/results/thermal_nominal_traces.csv`: nine deterministic configuration traces generated by the fixed cell-temperature ODE |
| Input checks | The associated `thermal_audit.json`, `operations_audit.json`, frozen cell-model JSON, and archived protocol identify the source, reserve endpoint and constants |
| Resampling | Past-held one-second grid; source gaps greater than 1.5 seconds remain unavailable; no future interpolation |
| Histories | 61 points covering t−60 through t; origins spaced 10 seconds apart; complete history and forecast intervals must fit within each reserve-limited trace |
| 20 features | For temperature, equivalent current and air temperature: last, mean, minimum, maximum, OLS slope per second and latest difference; plus capacity kWh and rolling resistance percent |
| Forecast target | Direct change T(t+h)−T(t), with h = 60, 120, 300 or 600 seconds; the predicted change is added to the origin temperature |
| Persistence | T̂(t+h)=T(t) |
| Linear trend | T̂(t+h)=T(t)+h × causal 60-second temperature slope |
| Physics hold | Fixed ODE forecast using current and air held at their origin values; a=4.344635339312832e−05 K/(A²s), b=0.002655462788692412 s⁻¹ |
| Ridge | `StandardScaler` plus `Ridge`, fitted only on permitted training cases; alpha grid 1, 100, 10000; intercept enabled |
| Histogram boosting | `HistGradientBoostingRegressor`; 40 or 80 iterations, learning rate 0.08, depth 3, at most 7 leaves, min leaf size 20, L2 0.0001, 64 bins, early stopping disabled |
| Outer validation | Nine leave-one-whole-configuration-out folds |
| Inner validation | Four deterministic folds inside the remaining eight configurations; two complete validation cases per fold; equal weight to each of the eight case MSEs |
| Hyperparameter selection | Lowest mean inner case MSE; first grid setting wins ties; outer test error is excluded |
| Randomness and compute | Seed 20261027, one compute thread, pinned numerical libraries |
| Number of fits | 432 inner ridge + 288 inner boosting + 36 outer ridge + 36 outer boosting = 792 |

The complete implementation is organized as named functions in `train.py`: `resample_past_held`, `features_at`, `build_examples`, `physics_forecast`, `estimator`, `nested_group_plan`, `fit_selected`, `run`, `compare_archived_metrics`, and `make_figures`. The estimator, feature and nested-validation functions preserve the archived algorithms. `implementation_preservation.json` records their AST comparison with the unchanged original source.

## Scope limits

The ODE hold-input baseline shares the target generator's coefficients. All nominal air values are 25 °C, and the generated temperature range is only 25–25.093186885353067 °C. Overlapping histories and forecast intervals are dependent; nine deterministic configurations are not nine independent physical tests. This experiment provides no measured-pack validation, field false-alarm rate, thermal-runaway onset prediction or warning lead time. The historical TUM dataset is separate from these generated training targets.
